# Gravar

**Gravar** is an open-source platform for multimodal video transcription, annotation, and interaction analysis. It is designed for researchers, clinicians, educators, and students who need to synchronize video, transcripts, waveforms, and rich annotations within a single workspace.

Unlike conventional transcription software, Gravar is built to support detailed analyses of human interaction. It combines transcript editing, synchronized media playback, waveform navigation, coding, notes, drawing overlays, and clip generation into an integrated environment that preserves the temporal organization of recorded events.

## Features

* Synchronized video, transcript, and waveform display
* Frame-accurate navigation and playback
* Dual-video support for comparative analyses
* Rich transcript editing with speaker management
* Line notes and project notes
* Coding and symbol systems for qualitative analysis
* Grouping and transcript organization tools
* Video and frame clip export
* Drawing and annotation overlays (lines, arrows, brackets, boxes, circles, text, and more)
* Search and replace tools
* Customizable transcript formatting
* Pop-out transcript and video windows
* Import support for multiple transcript formats, including:

  * DOTE (MacWhisper)
  * TSV
  * ELAN-compatible TSV
* Export to CSV and HTML

## Purpose

Gravar was developed to support the close analysis of naturally occurring interaction, particularly in conversation analysis, discourse analysis, augmentative and alternative communication (AAC), clinical education, and other forms of multimodal research.

The software emphasizes precise temporal alignment between media and transcript while providing tools for documenting interactional phenomena, coding behavior, creating teaching materials, and preparing research figures and video clips.

## Project Status

Gravar is under active development. New capabilities are continually being added, including expanded transcript importers, enhanced annotation tools, improved project management, and additional export formats.

Contributions, feature suggestions, and bug reports are welcome.
