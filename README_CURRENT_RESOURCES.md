# Gravar Current Resources — v0.6.212

Current standalone build: `Gravar_v0.6.212_Merge_Note_Dividers_Multi_Line_Delete.html`.

This release preserves the v0.6.211 Merge Line Note repair and adds two requested behaviors: multiple merged Line Notes are separated by a visible new-line / `-----` / new-line divider, and a Shift-selected row range can be deleted as one Undoable multi-line operation. Command/Ctrl-Delete and Command/Ctrl-Backspace preserve the selected range rather than collapsing it to one row. Project-home and Project Save media-reuse protections remain in place.

`index.html` is an identical copy of the named standalone HTML for GitHub/web deployment.
