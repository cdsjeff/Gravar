# Gravar v0.6.185 Current Resources

This package contains the current standalone Gravar web application and repository-ready resources.

- `index.html` — current Gravar application for GitHub Pages/static hosting
- `Gravar_v0.6.185_Force_PT_Explicit_Only.html` — versioned standalone application
- `CHANGELOG.md` — revision history by version
- `CHANGELOG_BY_DATE.md` — revision history organized by date
- `Gravar_v0.6.185_SHA256.txt` — checksums

Current release highlight: **Force PT timecodes** is now the sole trigger for copying a parent tier's Start/Stop/Duration to child tiers. This applies to both italic-Speaker and double-parentheses child tiers. When Force PT is unchecked, child tiers retain their own timing, including waveform-selected timecodes.
